1. Acesse developers.facebook.com → Meus Apps
2. Abra seu app → WhatsApp → Configuração da API
3. Copie o Phone Number ID e o WABA ID
4. Em Usuários do Sistema → Gerar token → selecione seu app → permissão whatsapp_business_messaging
5. Configure o webhook: https://iacrmapp.com.br/api/crm/whatsapp/webhook
